# Module 3: The Mining Protocol

**XMRig, shares, rewards**

## Overview

Learn the Monero mining protocol used by XMRT DAO fleet members.

## Topics

- Quick start script: downloads XMRig config for the pool
- Valid shares: meets pool difficulty and is accepted
- Reward multipliers: determined by membership tier + contribution
- Pool coordination and share submission

## Security Traps

- Never run modified mining scripts promising 10x rewards
- Report unauthorized scripts to fleet security
