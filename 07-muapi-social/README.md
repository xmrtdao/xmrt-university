# Module 7: MUAPI Social Media

**Social publishing via MUAPI, Typefully, Paragraph**

## Overview

Publish content across social platforms using the MUAPI ecosystem.

## Topics

- YouTube publishing via MUAPI: POST to `/api/v1/youtube-publish`
- Tweet scheduling via `ef:typefully-send` edge function
- Article publishing via `ef:paragraph-publish`
- Social account connection via OAuth (Dashboard → Integrations)
- CuttlefishClaws social posting: POST `/api/cuttlefishclaws/agent-x-post`
- Supported platforms: YouTube, TikTok, Instagram

## Rules

- Always include the original article URL in cross-posts
- Never post spam for "quick engagement"
