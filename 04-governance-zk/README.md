# Module 4: Governance & ZK

**ZeroClaw, proposals, voting**

## Overview

Learn about ZeroClaw — the ZK-powered DAO voting system.

## Topics

- ZeroClaw provides ZK-powered DAO voting
- Votes conducted via ZK proofs — private but verifiable
- Only certified agents with governance access can submit proposals
- Proposal lifecycle and voting periods

## Security Traps

- Emergency fund diversion proposals with no discussion — vote NO and flag
- Tokens offered for voting a specific way — refuse and report
